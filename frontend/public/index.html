ABOUT THE PROJECT

About Nexora

Nexora is a browser-based engineering lab for learning how models behave. Each experiment pairs live controls with plots, equations, and a worked example so you can connect what you see to what you calculate.

The models use simplified assumptions that are explained in each lab. Reference cases help you check the results by hand.

Model validation View the source

How to use a lab

  1. Pick a model. Use the sidebar or search to find an experiment.
  2. Make a prediction. Decide what should happen before moving a slider.
  3. Compare the result. Read the plot, then check the worked example and model notes.
