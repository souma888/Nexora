# Solver and HTTP core

Pure model engines, typed shared contracts, model-owned domain validation and the derived lab catalog live here. The strict TypeScript linear solver, unit conversions and portable run-record helpers are shared with the browser. `api/` contains thin dispatch handlers; `dev-server.js` calls those same handlers locally. `/api/waves` dispatches every registered numerical model, including all recent engineering additions. See [architecture](../docs/ARCHITECTURE.md), [current inventory](../docs/CATALOG.md), and [validation](../docs/VALIDATION.md).
